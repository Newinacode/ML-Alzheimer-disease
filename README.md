
# Use of Logistic Regression and Neural Network for Alzhemer Disease Prediction




## Installation

Creating virtual Environment

Mac
```bash
python3 -m venv venv
```

Windows
```bash
python -m venv venv
```

Activate Virtual Environment
```bash
source venv/bin/activate
```

Install package in virtual environment
```bash
pip install -r "requirements.txt"
```

Downloading dataset locally
```bash
  python setup.py
```

Running notebook server
```bash
jupyter notebook
```
